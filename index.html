🛠️ Troubleshooting Common Issues

Even with a smooth setup, you might hit a small snag. Here's how to fix common problems:

Menu doesn't detect WARDOGS running

Make sure WARDOGS is running in Windowed or Borderless mode (Fullscreen can block overlays). Also, try running the mod menu as Administrator by right-clicking it and selecting "Run as administrator".

Overlay panels are showing but laggy

Lower the update rate in the menu's performance settings. Disable panels you don't use during intense moments — the menu is designed to be lightweight, but too many visible panels can reduce FPS.

Game crashes when launching the menu

Update your graphics drivers and Windows. Then restart both the game and the menu. If the problem persists, delete the configuration file (usually located in %AppData%\WARDOGSMenu\) and re-launch to create a fresh config.

Hotkeys are not responding

Check if another app is using the same key combination. Inside the menu, you can see if the key binding was properly saved. Rebind the key and test immediately.
